### Rules confirmed by the user (2026-09-03) — these are settled
- **Self-nomination: NOT allowed** (both roles). Enforced in `nomineeCandidatesFor()`, which always filters out `CURRENT_USER`.
- **Peer Appreciation nominee scope = anyone in CIDC.** Employees may pick any person in the company (`MANAGERS + EMPLOYEES`), minus themselves. Managers stay restricted to their own team (`MY_TEAM`) for Rising Star / Outstanding.
- **Submit is submit-only — one nomination per award, per month, no editing after.** So the dashboard CTA reads `Submit Nomination` for as long as anything is outstanding and becomes `View Nomination` only once everything is in; there is deliberately no "Continue Nominating" / edit affordance anywhere.

### Design corrections applied 2026-09-03 (post-review, all live)
- Preview seed switched **off** — `SEED_A_SUBMITTED_NOMINATION = false`; everyone starts un-submitted.
- Dropped the "Continue Nominating" CTA variant — `Submit Nomination` while anything is outstanding, `View Nomination` once everything is in.
- **Breadcrumb corrected** — the nominator pages had wrongly used the *admin* breadcrumb; both now use the Employee/Manager one, extracted to `SpotlightBreadcrumb.tsx` (30px boxed arrow, leading `/`, 13px crumbs, current page bold).
- Form page runs **full width** (removed the 860px cap).
- **Every action button is theme indigo `#6366F1`** (hover `#5B5FDE`); Spotlight violet is an identity accent only, never on anything clickable.
- Selected nominee shows **picture, name, role, email** only — Employee Code / Email cells removed (department dropped too).
- Confirm modal **centre-aligned**, employee code removed from its copy.
- **Submit navigates straight to the dashboard**; the recap sits behind `View Nomination`. The module's toast was removed with it.
